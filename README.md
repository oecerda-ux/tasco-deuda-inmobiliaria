# Tasco - Deuda Inmobiliaria

Informe Ejecutivo de Deuda Inmobiliaria (Directorio), generado a partir del
pipeline interno de reportería. Incluye resumen ejecutivo, panel directivo
consolidado por proyecto, estructura de deuda, calendario de vencimientos,
bancos e intereses, cobranza por cliente y matriz obra/ventas.

Abrir `Reporte_Deuda_Inmobiliaria_Tasco.html` en el navegador.
